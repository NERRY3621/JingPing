01 / CAPABILITIES

不是只屏蔽一个 App

通用跳过规则 + 系统级组件禁用 + 进程内传感器拦截。能单独用，也能叠着用。

A11Y
01

开屏自动跳过

识别 SplashShellActivity / HotSplashActivity 等开屏窗口，按文字或控件 ID 点「跳过」；右下角的「跳过 3」也支持。

A11Y
02

广告页自动返回

纯开屏广告页找不到按钮时，自动按一次返回键。只对已知开屏广告页生效，不碰启动壳。

A11Y
03

摇一摇跳转拦截

广告页把用户摇到淘宝、京东、拼多多或浏览器时，立即返回原应用。作为没有 LSPosed 时的兜底。

ROOT
04

深度净化

用系统 pm disable 禁用广告 SDK 的 Activity，比如 B 站 HotSplashActivity。不改 APK，可随时恢复。

LSPOSED
05

摇一摇源头拦截

在目标应用进程内拦截广告 SDK 的加速度传感器注册与外部跳转，让「扭一扭」拿不到数据。

OPTIONAL
06

后台守护

前台服务 + 常驻通知、开机自启、进程被杀后恢复、无障碍掉线自动恢复。不开启时 App 不驻留后台。

02 / INTERFACE

莱茵生命终端风格

暖灰纸面、墨黑字、琥珀金、细线档案卡片、档案编号与淡网格。功能仍然是净屏的。

03 / QUICK START

三步开始

下载安装后，App 里有带按钮的内置教程；下面是给第一次用的人看的简版。

1

安装并开启无障碍

从 Release 下载 APK，安装后打开「使用教程 → 第 1 步」。有 Root/Shizuku 可一键开启；没有就到系统无障碍页手动打开「净屏 · 开屏广告跳过」。

2

按需做深度净化

勾选常用 App，扫描组件，一键净化。B 站会禁用 HotSplashActivity，冷启动直接进首页。需要 Root 或已授权的 Shizuku。

3

想拦摇一摇就开 LSPosed

在 LSPosed 启用「净屏」，勾选作用域，强行停止目标 App 再打开。只使用模块时，不要开启后台守护，App 不会驻留后台。

BILIBILI / EXAMPLE

B 站开屏页，一行命令就能停用

«净屏» 的深度净化会自动执行这条命令。每台设备本地生效，不会随 APK 分发；B 站更新后重新扫描即可。

pm disable --user 0
tv.danmaku.bili/
tv.danmaku.bili.splash.ad.page.HotSplashActivity
04 / MODES

两种用法，不打架

想开箱即用选 App 模式；不想跑后台选 LSPosed 模式。也可以两个都开。

MODE A

App 模式

  • 无障碍自动点「跳过」，覆盖 App 最多
  • Root / Shizuku 深度净化广告 Activity
  • 可选后台守护，开机自启、掉线自动恢复
  • 适合「不想折腾 LSPosed」的人
MODE B

LSPosed 模式

  • 模块在目标应用进程内运行
  • 拦截广告 SDK 的加速度传感器注册
  • 拦截广告 SDK 启动外部购物 App / 浏览器
  • 完全不需要让净屏常驻后台

隐私

  • 未申请 INTERNET 权限，不联网
  • 无障碍只读取窗口节点找「跳过」
  • 规则、日志、配置只在本机
  • 深度净化改的是系统组件状态，可恢复

限制

  • 没有 LSPosed 时，摇一摇只能做事后跳转拦截
  • Canvas / SurfaceView 绘制的跳过按钮可能识别不到
  • 广告 12 秒后才加载可能错过窗口
  • 卸载前请先在 App 内恢复被禁用的组件
05 / FAQ

常见问题

更多细节、构建方法和完整教程在 GitHub README。

状态全绿，但某个 App 还是不跳过？

先确认总开关和「自动点击跳过」都开着；如果按钮是 Canvas 绘制，无障碍看不到，改用深度净化禁用广告 Activity，或启用 LSPosed 模块。

B 站更新后开屏又回来了？

更新可能重新启用组件。重新进「深度净化 → 扫描 → 一键净化」即可。

LSPosed 不生效？

确认模块已启用、作用域已勾选、目标 App 已强行停止并重开。管理器可能寄生在 com.android.shell，从通知栏进入更稳。

需要一直让 App 挂在后台吗？

不需要。只使用 LSPosed 模块时完全不用后台；App 模式可以选开启「后台守护」，由前台服务负责保活，不需要手动挂。

卸载前要注意什么？

先在「深度净化 → 恢复」里还原所有已禁用的广告 Activity，再卸载。
